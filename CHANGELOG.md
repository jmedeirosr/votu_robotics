# Changelog

Todas as alterações relevantes do Votu FieldOps serão registradas neste arquivo.

## [1.0.0] - 2026-07-29

### Adicionado

- Pipeline reproduzível de compilação standalone com Nuitka.
- Pacote Debian nativo para ARMv7, ARM64 e AMD64.
- Instalador gráfico baseado no Qt Installer Framework.
- Criação de entrada no menu, atalho e ferramenta de desinstalação.
- Manifesto de release, catálogo de atualização e checksums SHA-256.
- Comandos para builds debug, release e nightly.
